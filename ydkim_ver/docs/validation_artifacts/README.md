# Full-stack validation artifacts

This directory contains reproducible data and figures generated by
`../generate_validation_figures.py`:

- `full_stack_validation_data.json`: environment, experiment, quality, and
  backend-agreement data;
- `full_stack_fidelity.{png,pdf}`: PLS/MLE infidelity versus shots;
- `full_stack_physicality.{png,pdf}`: nonphysical-estimate frequency;
- `backend_agreement.{png,pdf}`: stage-by-stage NumPy/JAX differences.

AI disclosure: the experiment code, figure design, captions, and this guide
were generated with OpenAI Codex assistance on 2026-08-17. Independent review
is required before the artifacts are described as verified.
